# 가이드 주제 대기열 (주간 자동 작성용)

매주 화요일 자동 세션이 위에서부터 `[ ]` 한 개를 골라 글을 쓰고 `[x]`로 바꾼다. 사람이 주제를 추가·삭제·순서 변경할 수 있다.
글 작성 규칙은 CLAUDE.md "금액 계산의 핵심 규칙"과 아래 공통 규칙을 따른다.

## 공통 규칙
- 수치는 저장소 스냅샷(`data/snapshot/*.json`)에서 계산하거나 CLAUDE.md에 적힌 확정 규칙만 쓴다. 확인되지 않은 금액·날짜·기관 발표는 적지 않는다. 모르면 "지자체 공고 확인"으로 쓴다.
- 본문 2,000~3,000자, h2 4~6개, 표 1개 이상, FAQ 2~3개, `sources`에 누리집·지침 링크. 기존 가이드 2편 이상으로 내부 링크.
- 수기 작성·전문가 검수·현장 사례 주장을 하지 않는다. 2027 전망·예산 수치를 쓰지 않는다.
- 파일은 `content/guides/weekly.ts`에 추가하고 `index.ts`의 GUIDES에 포함돼 있어야 한다. 기존 글·페이지 구조는 바꾸지 않는다.

## 대기열
- [ ] 전기차 완속충전기 설치 지원: 아파트·단독주택별 절차와 확인할 것 (충전인프라 보조 사업 신청 주체·절차 중심, 금액은 공고 확인)
- [ ] 아파트 전기차 충전 환경 확인법: 입주자대표회의 동의, 전력 증설, 공용 충전기 사용 규칙
- [ ] 중고 전기차 보조금 승계 실무: 의무운행 8년 승계, 이전등록 때 확인할 서류
- [ ] 법인·개인사업자 전기차 보조금: 사업장 기준 신청, 대수 상한, 세무 처리에서 흔한 오해
- [ ] 전기차 겨울철 주행거리와 보조금 차종 선택: 히트펌프·배터리 용량이 실사용에 미치는 영향 (수치는 제조사 공인 인증값만)
- [ ] 전기차 보조금 선정 취소 사유 모음: 출고 지연·명의 변경·서류 미비 사례와 대응
- [ ] 전기차 취득세·개별소비세 감면 신청 흐름: 등록 창구에서 무엇을 확인하는가 (감면액 단정 금지, 법령 링크)
- [ ] 전기차 보조금 공고문 읽는 법: 물량 구분·우선순위·접수 방법 항목별 해설
- [ ] 리스·장기렌트 전기차 보조금: 견적서에서 국비·지방비 반영 확인하는 법
- [ ] 시·도별 전기차 보조금 공고 패턴: 단일 공고 vs 시·군별 공고의 차이와 신청 전략 (local-price.json·remain.json 계산)
- [ ] 전기차 보조금 잔여 물량이 가장 빨리 소진된 지역 유형 분석 (remain.json 계산, 원인은 추정으로 표기)
- [ ] 전기차 보조금 신청 서류 반려 사유 TOP: 등본 발급일·명의·주소 표기 문제
